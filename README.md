# Cyber Security Academy V3.1

Version corrigée de la plateforme de formation.

## Modifications
- « Exécuter » devient « Essayer la commande ».
- Les informations de l'entreprise ne sont plus affichées directement dans le pied de page.
- Elles sont accessibles uniquement via « Mentions légales ».
- L'évaluation de chaque module est désormais obligatoirement un **cas pratique**.
- Pour valider un module, l'étudiant doit utiliser **toutes les commandes du module**, dans l'ordre attendu.
- La validation de l'évaluation finale est elle aussi un cas pratique de synthèse utilisant toutes les commandes du parcours.
- Les commandes restent simulées et inertes.
- Persistance localStorage, export JSON, thème clair/sombre et taille de texte conservés.
